# Changelog

## 0.2.0 — 2026-08-10

- Renamed the application to Parallel.
- Added Windows and Linux distributions.
- Added standard share rooms and administrator-managed collaboration rooms.
- Added multiple viewers and high-resolution WebRTC streaming.
- Added host-approved Linux remote control.
- Added clipboard sharing and file transfer.
- Added persistent device names and improved local-network discovery.
- Redesigned the dashboard, viewer and incoming-request interfaces.

Windows-host remote input is not included in this release.
