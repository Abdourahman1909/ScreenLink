# Security

## Supported version

Security fixes are provided for the latest published version of Parallel.

## Reporting a vulnerability

Please report security issues privately to **zaynmohamed063@gmail.com**. Do not include passwords, access tokens, personal files, or other sensitive information in a public GitHub issue.

Include the Parallel version, operating system, reproduction steps and the expected impact when possible.

## Safe usage

- Download Parallel only from this repository's Releases page.
- Verify the SHA-256 checksums supplied with each release.
- Use Parallel only on a trusted private network.
- Protect rooms with a password when other devices share the network.
- Grant remote control only to a person you recognize.
